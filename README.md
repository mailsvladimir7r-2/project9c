# Simple Site — Верстка вебсторінки за макетом Figma

## Опис мети
Практично об'єднати вивчені технології чистого CSS (семантичний HTML5, CSS-змінні у `:root`, моделі розкладки Flexbox та CSS Grid, структурування класів за методологією BEM) у цілісний працюючий вебінтерфейс за дизайн-макетом **Simple Site**.

## Використані технології
* **HTML5:** семантичні теги (`header`, `nav`, `main`, `section`, `footer`) та ієрархія заголовків `h1–h3`.
* **CSS3 (Custom Properties):** дизайн-токени кольорів, шрифтів і відступів у `:root` з підключенням через `var()`.
* **Flexbox та CSS Grid:** побудова навігації, карток досягнень та загальної сітки сторінки з використанням `gap`.
* **Методологія BEM:** іменування класів за схемою `блок__елемент--модифікатор` (наприклад, `.nav__link--active`, `.button--primary`).
* **GitHub Pages:** публікація готового статичного сайту.

## Звіт про перевірку в браузері
Розкладку сторінки перевірено в браузері. Інтерфейс побудовано на семантичних тегах HTML5, кольори та шрифти винесені в змінні `:root`, компоненти та контентні блоки скомпоновані за допомогою Flexbox і CSS Grid із властивістю `gap`, класи структуровані за методологією BEM, горизонтальний скрол відсутній.
Use code with caution.
